# 极简二维码 - 浏览器插件

极简界面 + 全能扫码 + 全平台二维码插件


| [Chrome](https://chromewebstore.google.com/detail/qrcode/hflmenbgannghieoagnegjlbmlnllkhc) | [Edge](https://microsoftedge.microsoft.com/addons/detail/clkjmabfjboobjkemgknlgpjjlhdghbp) | [Firefox](https://addons.mozilla.org/zh-CN/firefox/addon/qrcode-simple/) |

## 功能:

**1. 二维码生成:**

  - 当前页面地址二维码: 点击插件工具栏图标
  - 选中文本生成二维码: 在选中文本上右键
  - 输入文字实时生成二维码: 工具栏弹窗默认只显示二维码, 鼠标划过二维码底部的白边即自动展开输入框(点击箭头可收起), 输入即实时更新二维码

**2. 二维码识别:**

  - 网页图片二维码识别: 在图片上点击右键选择识别方式
  - 网页任意位置截图识别二维码: 在网页空白处右键选择"截图识别", 框选区域识别
  - 一键截屏识别二维码: 在网页空白处右键选择"一键截屏识别", 直接识别整个视口, 无需框选; PDF 等无法注入脚本的页面在新标签页里识别
  - 扫描动画: 一键截屏识别在整屏、图片识别在图片区域播放上下往返的扫描动画, 识别期间持续扫描, 结束后淡出再弹出识别结果
  - 网页截屏识别二维码: 工具栏图标上点击右键进行截图识别
  - 本地/剪贴板图片与摄像头扫码: 在工具栏图标上点击右键选择"上传 / 粘贴 / 拍照扫码", 优先在当前页弹出识别面板, 可粘贴、拖放、选择文件, 也可切换到摄像头实时扫码; 无法注入脚本的页面才打开新标签页
  - 多码识别: 自动识别图片中的所有二维码和条形码, 多个结果会逐条列出

**3. 截图工具:**

  - 截图复制/保存: 框选后可直接复制到剪贴板或保存为图片, 也可作为简单截图工具使用
