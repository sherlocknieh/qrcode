# 极简二维码 - 浏览器插件

极简界面 + 全能扫码 + 全平台二维码插件


| [Chrome](https://chromewebstore.google.com/detail/qrcode/hflmenbgannghieoagnegjlbmlnllkhc) | [Edge](https://microsoftedge.microsoft.com/addons/detail/clkjmabfjboobjkemgknlgpjjlhdghbp) | [Firefox](https://addons.mozilla.org/zh-CN/firefox/addon/qrcode-simple/) |
| --- | --- | --- |

## 功能:

**1. 二维码生成:**

  - 当前页面地址二维码: 点击插件工具栏图标
  - 选中文本生成二维码: 在选中文本上右键
  - 输入文字实时生成二维码: 工具栏弹窗默认只显示二维码, 点击二维码后编辑区像抽屉一样从下方滑出, 输入即实时更新二维码
  - 二维码快捷操作: 展开编辑区后, 输入框下方提供复制图片、下载 PNG、下载 SVG(透明背景) 三个按钮
  - Linux 下的 Chrome / Edge 提示: 扩展弹窗窗口拿不到输入法, 弹窗里只能输入英文; 需要输入中文时把 `popup.html` 当普通标签页打开(地址栏输入 `chrome-extension://<扩展 ID>/popup.html`), 或先把文字复制好再粘贴进输入框

**2. 二维码扫描:**

  - 工具栏弹窗扫码: 展开输入框后, 面板下方直接提供本地/粘贴图片、扫描当前页面、打开摄像头扫描三个扫码入口
  - 网页图片二维码扫描: 在图片上点击右键选择扫描方式
  - 扫描屏幕二维码: 在网页空白处或工具栏图标上右键选择"扫描当前页面", 直接扫描当前视口, 无需框选; PDF 等无法注入脚本的页面在新标签页里扫描
  - 扫描动画: 扫描屏幕在整屏、图片扫描在图片区域播放上下往返的扫描动画, 扫描期间持续扫描, 结束后淡出再弹出扫描结果
  - 本地/剪贴板图片: 在工具栏图标上点击右键选择"本地上传/粘贴图片", 优先在当前页弹出扫描面板, 可粘贴、拖放、选择文件; 无法注入脚本的页面才打开新标签页
  - 摄像头扫码: 右键菜单选择"打开摄像头扫描", 在新标签页里实时扫码 (摄像头只在扩展页运行, 弹窗失焦即关闭)
  - 多码扫描: 自动扫描图片中的所有二维码和条形码
  - 多码点选: 扫描命中多个码时只在各码上出现绿点, 不弹出结果列表; 点哪个码就把通知切到哪个码, 可连续点选; 扫描屏幕、网页图片、粘贴/本地图片、摄像头都适用; 新标签页里扫描时点完最后一个码、关掉通知才关闭页面

**3. 框选重扫:**

  - 扫描结果画面上可以直接拖框另选一块重扫; 不需要时点空白处或按 Esc 退出
