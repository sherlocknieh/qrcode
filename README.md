# 极简二维码 - 浏览器插件

极简界面 + 全能扫码 + 全平台二维码插件


| [Chrome](https://chromewebstore.google.com/detail/qrcode/hflmenbgannghieoagnegjlbmlnllkhc) | [Edge](https://microsoftedge.microsoft.com/addons/detail/clkjmabfjboobjkemgknlgpjjlhdghbp) | [Firefox](https://addons.mozilla.org/zh-CN/firefox/addon/qrcode-simple/) |

## 功能:

**1. 二维码生成:**

  - 当前页面地址二维码: 点击插件工具栏图标
  - 选中文本生成二维码: 在选中文本上右键
  - 输入文字实时生成二维码: 工具栏弹窗默认只显示二维码, 鼠标划过二维码底部的白边即自动展开输入框(点击箭头可收起), 输入即实时更新二维码

**2. 二维码扫描:**

  - 网页图片二维码扫描: 在图片上点击右键选择扫描方式
  - 网页任意位置截图扫描二维码: 在网页空白处右键选择"截图扫描", 框选区域扫描
  - 一键截屏扫描二维码: 在网页空白处右键选择"一键截屏扫描", 直接扫描整个视口, 无需框选; PDF 等无法注入脚本的页面在新标签页里扫描
  - 扫描动画: 一键截屏扫描在整屏、图片扫描在图片区域播放上下往返的扫描动画, 扫描期间持续扫描, 结束后淡出再弹出扫描结果
  - 网页截屏扫描二维码: 工具栏图标上点击右键进行截图扫描
  - 本地/剪贴板图片: 在工具栏图标上点击右键选择"本地上传/粘贴图片", 优先在当前页弹出扫描面板, 可粘贴、拖放、选择文件; 无法注入脚本的页面才打开新标签页
  - 摄像头扫码: 右键菜单选择"摄像头扫码", 在新标签页里实时扫码 (摄像头只在扩展页运行, 弹窗失焦即关闭)
  - 多码扫描: 自动扫描图片中的所有二维码和条形码, 多个结果会逐条列出
  - 多码点选: 扫描命中码后在各码上出现蓝点并同时给出结果, 点哪个码就把通知切到哪个码, 可连续点选; 一键截屏、框选截图、网页图片、粘贴/本地图片、摄像头都适用

**3. 截图工具:**

  - 截图复制/保存: 框选后可直接复制到剪贴板或保存为图片, 也可作为简单截图工具使用
